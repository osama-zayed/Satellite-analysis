# Earth Observation Eye (EOE)

![Earth Observation Eye](https://osamazayed.com/images/portfolio-7.webp)

## Overview

Earth Observation Eye (EOE) is a project focused on data analysis based on satellite images. 

### Key Features

- **Data Analysis Models**: 
  - Developed models to detect slums and building density, aiding stakeholders in planning and development.
  
- **API Development**: 
  - Allows users to integrate AI models into their applications for easy access to data and analytics.
  
- **Comprehensive Website**: 
  - Built a site with sections for testing and statistics, facilitating data interaction.
